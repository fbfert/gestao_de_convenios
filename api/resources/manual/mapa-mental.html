Como ler: o atendimento sempre segue a coluna azul de cima para baixo (Solicitação → Guia → Antecipação → Sessões → Analítico → Conciliação). As colunas verde e âmbar são cadastros e telas de suporte que alimentam esse fluxo, mas não têm uma ordem fixa entre si. A coluna roxa mostra quem pode ver/fazer o quê — detalhes de cada permissão estão na tela de Permissões, descrita no manual completo.
